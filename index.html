Set up sync ♡

Takes 2 minutes. Only needs to be done once — then share the page with your partner and you're both connected forever.

1
Go to jsonbin.io and create a free account.
2
Click API Keys in the top menu → copy your Master Key (starts with $2a$...).
3
Click Bins → Create New Bin, paste {} as content, click Create. Copy the Bin ID from the URL (looks like 64a3f...).
4
Paste both below and click Save. Your partner will be asked for the same two values on their first visit.
